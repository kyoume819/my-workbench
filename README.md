# 我的工作台 (My Workbench)

一个纯本地运行的个人工作生活管理工具，单文件HTML应用，无需安装、无需联网、无需账号。

---

## 这是什么？

这是一个**只在你自己电脑浏览器里运行**的个人工作台，把工作、自媒体、健身、饮食、攒钱这些分散的事整合到一个页面里管理。打开浏览器就能看到今天要做什么，所有数据都存在你自己电脑上，安全可控。

## 核心特点

- **零依赖**：单个HTML文件，双击就能用
- **纯本地**：数据存在你电脑的文件夹里，不上传任何服务器
- **无需登录**：打开就用，不用注册账号
- **iOS风格毛玻璃**：半透明磨砂质感，界面清爽
- **自动保存**：所有操作自动写入本地文件，关闭重开不丢失

## 功能模块

### 1. 首页总览
打开APP第一眼看到的仪表盘：
- 今日待办摘要
- 快速备忘（随手记，回车保存）
- 各板块待办重点汇总

### 2. 今日计划
当天任务清单：
- 添加任务，设置高/中/低优先级
- 勾选完成，删除任务
- **日常任务**：勾选"每天重复"，每天自动出现，不用每天手动加
- **时间段重复**：指定结束日期，那一段时间里每天自动显示这个任务

### 3. 自媒体
内容创作追踪看板：
- 新建选题，选择发布平台（小红书/公众号/B站/知乎）
- 状态流转：选题中 → 写稿中 → 已发布
- 顶部统计各状态数量

### 4. 开发工作
多项目任务管理：
- 新建多个项目，标签页切换
- 每个项目下独立的待办列表
- 待办可设优先级、勾选完成

### 5. 咨询工作
客户跟进管理：
- 记录每个咨询事项的阶段
- 设置下次跟进日期
- 即将到期的跟进自动高亮提醒

### 6. 健身计划
训练管理：
- 每周训练计划（周一到周日）
- 预置18种常见运动、9种运动器械
- 记录每次训练内容
- 可自定义添加新运动和器械

### 7. 饮食计划
饮食记录与营养计算：
- 按日期记录三餐
- 预置18种常见食物营养数据（每100g）
- 输入食物+克重，自动算热量、蛋白质、脂肪、碳水
- 减肥目标设置（目标体重、每日热量目标）
- 自动联动健身记录估算运动消耗

### 8. 攒钱计划
存钱目标追踪：
- 设定存钱目标金额和目标日期
- 进度条显示完成百分比
- 记录每笔存钱，可删除
- 支持多种存钱方法（52周法、365天法、每月定额）

### 9. 数据与设置
数据管理：
- 查看各模块数据统计
- 导出备份（下载JSON文件）
- 恢复数据（导入JSON备份）
- 修改数据文件夹位置

## 使用方法

1. 用 **Chrome 或 Edge** 浏览器打开 `个人工作台.html`
2. 首次使用选择一个文件夹用于保存数据（建议在桌面新建空文件夹）
3. 所有数据自动保存在本地，关闭重开不丢失

## 技术说明

- **纯前端**：单个HTML文件，所有CSS、JS都内联
- **本地存储**：使用 File System Access API 读写本地文件
- **文件夹记忆**：用IndexedDB记住文件夹位置，下次打开自动恢复，不用重新选
- **无依赖**：不加载任何外部库、字体、图片资源

## 文件说明

| 文件 | 说明 |
|------|------|
| `个人工作台.html` | 正式版应用，双击即用 |
| `PRD.md` | 产品需求文档（完整功能说明） |
| `开发计划.md` | 分阶段开发计划 |
| `设计原型.html` | 早期设计稿 |

## 注意事项

- 只支持 **Chrome / Edge** 浏览器（需要File System Access API）
- 数据完全存在本地，清理浏览器缓存不会丢
- 换电脑的话，把数据文件夹一起拷过去就行
