# 我的工作台

一个纯本地运行的个人工作生活管理工具，单文件HTML应用，无需安装、无需联网、无需账号。

## 功能模块

- **首页总览**：今日计划摘要、快速备忘、各板块待办重点汇总
- **今日计划**：任务管理、优先级、日常重复任务、时间段重复
- **自媒体**：选题追踪、写稿状态流转、发布记录
- **开发工作**：多项目管理、待办任务、截止日期
- **咨询工作**：客户跟进管理、提醒日期高亮
- **健身计划**：周训练计划、运动器械库、训练记录
- **饮食计划**：食物营养计算（热量/蛋白质/脂肪/碳水）、减肥目标
- **攒钱计划**：存钱目标、进度追踪、存钱记录
- **数据与设置**：本地数据备份、恢复、文件夹管理

## 使用方法

1. 用 Chrome 或 Edge 浏览器打开 `个人工作台.html`
2. 首次使用选择一个文件夹用于保存数据（建议新建空文件夹）
3. 所有数据自动保存在本地，关闭重开不丢失

## 技术特点

- 单文件HTML，零依赖，双击即用
- 使用 File System Access API 实现本地文件持久化
- IndexedDB 记忆文件夹位置，无需每次重新选择
- 纯前端运行，数据不出本机
- 蓝白简洁配色，适配桌面使用
